# Encryption / Decryption Tool

A Python-based encryption and decryption tool developed for cybersecurity learning and educational purposes.

## Project Overview

This project demonstrates secure message encryption and decryption using the Fernet symmetric encryption algorithm provided by the Python `cryptography` library.

The tool generates a secure encryption key, stores it locally, and uses the same key to encrypt and decrypt messages.

## Features

- Generate a secure encryption key
- Encrypt plaintext messages
- Decrypt encrypted messages
- Fernet symmetric encryption
- Local key storage
- Command-line menu interface
- Error handling for invalid encrypted messages
- Secure key exclusion using `.gitignore`

## Technologies Used

- Python 3
- Cryptography
- Fernet Symmetric Encryption
- Kali Linux
- Git & GitHub
